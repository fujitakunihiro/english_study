# 英文法の例文練習

中学・高校英文法を例文で学ぶ、Docker で動作する静的 Web サイトです。文法の切り替え、和訳、検索、英文の音声再生に対応しています。

## 起動

Docker Desktop を起動し、このフォルダで実行します。

```powershell
docker compose up --build -d
```

ブラウザで http://localhost:8090 を開きます。

## 停止

```powershell
docker compose down
```

## 操作

- 「中学」「高校」を切り替えます。スマートフォンでは文法メニューから項目を検索・選択し、PC では左の一覧から選択します。文法を選ぶと例文までスクロールし、レベル切り替えではスクロールしません。
- 例文の再生ボタンで、ブラウザ標準の音声合成による英語読み上げを再生します。
- スマートフォンの文法メニューから、文法名を検索できます。

音声はブラウザと OS の音声合成機能を使用します。
